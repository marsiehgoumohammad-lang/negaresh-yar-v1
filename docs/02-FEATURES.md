# Negaresh Yar V1
## Feature Specification Document

---

# Feature Philosophy

Negaresh Yar V1 is a focused commercial product.

Only business-critical features are included.

Every feature must improve:
- customer acquisition
- service delivery
- content authority
- operational efficiency

No unnecessary complexity is allowed.

---

# Public Website Features

## 1. Premium Landing Page

The homepage must create trust within the first seconds.

Requirements:

- Custom-designed layout
- No pre-built templates
- Strong brand identity
- Professional typography
- Clear service explanation
- Mobile-first responsive design

Main sections:

- Hero section
- Services overview
- AI judicial interpretation introduction
- Content section
- Contact section

---

# 2. AI Judicial Document Interpretation

Purpose:

Allow visitors to upload judicial documents and receive a simplified explanation.

Supported input:

- PDF files
- Images

AI Provider:

Google Gemini API only.

---

Workflow:

1. User uploads document.
2. System validates file.
3. Document is sent to Gemini.
4. AI analyzes the content.
5. User receives a simple explanation.

---

Requirements:

- Clean upload interface
- Clear user guidance
- Error handling
- Secure file processing

---

# 3. Social Contact Request System

Purpose:

Supported platforms:

- WhatsApp

- Bale

# 5. AI Article Evaluation System

Articles must pass quality evaluation before publishing.

Evaluation criteria:

- Content quality
- SEO optimization
- Readability

Publishing rule:

80+
