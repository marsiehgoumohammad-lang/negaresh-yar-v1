# Negaresh Yar V1
## Admin Panel Specification

---

# Purpose

The admin panel is an internal management system.

It is not a customer dashboard.

---

# Design Requirements

The admin panel must be:

- Clean
- Professional
- Fast
- Simple

Avoid:

- Complex dashboards
- Unnecessary charts
- Enterprise complexity

---

# Admin Modules

---

# Dashboard

Purpose:

Quick overview.

Information:

- Article count
- Published content
- AI requests
- Recent invoices

---

# Article Management

Features:

- Create article
- Edit article
- Delete article
- Publish article
- Manage SEO fields

---

# AI Writer

Purpose:

Generate professional articles.

Workflow:

1. Enter topic
2. Generate draft
3. Evaluate content
4. Improve article
5. Publish

---

# AI Evaluation

Display:

- Content score
- SEO score
- Readability score
- Final score

Publishing requirement:

Score must be 80 or higher.

---

# AI Interpretation Management

Features:

- View requests
- View AI responses
- Manage stored files

---

# Invoice Management

Features:

- Create invoice
- Generate PDF
- Print invoice

---

# Social Media Management

Admin can update:

- WhatsApp link
- Telegram link
- Rubika link
- Eitaa link
- Bale link

---

# SEO Management

Manage:

- Default title
- Description
- Keywords
- Sitemap settings

---

# Authentication

Only administrator access exists.

No public account system.

---

# Future Expansion

Possible:

- Multiple admins
- Permissions
- Advanced analytics
